Java Fundamentos: orientação a objetos

Introdução ao paradigma orientado a objetos e à ideia de representar problemas por entidades, objetos, classes e interações.

Série

Java Fundamentos Parte 1 de 6

Orientação a objetos é uma forma de pensar problemas usando entidades, objetos e interações entre eles.

Paradigmas de programação

Um paradigma de programação é uma forma de organizar o raciocínio para resolver problemas com código.

Em vez de ser apenas uma regra de sintaxe, um paradigma influencia a maneira como pensamos na solução: quais partes o sistema terá, como essas partes se relacionam e como o comportamento será organizado.

Existem vários paradigmas de programação. Um dos mais conhecidos é a Programação Orientada a Objetos, também chamada de POO ou OOP.

O que é orientação a objetos

Na orientação a objetos, não pensamos no sistema apenas como uma sequência de tarefas.

Pensamos em entidades que fazem parte do problema e em como essas entidades interagem entre si.

Essas entidades podem representar elementos do mundo real ou conceitos importantes do sistema, como:

  • cliente;
  • produto;
  • pedido;
  • usuário;
  • pagamento;
  • imposto.

A partir dessas entidades, criamos classes e objetos para organizar o código.

Representando problemas do mundo real

A POO ajuda a transformar partes de um problema real em estruturas dentro do código.

Por exemplo, em um sistema de controle de clientes, o cliente real pode ser representado no sistema por uma classe Cliente.

Essa classe pode concentrar informações e comportamentos relacionados ao cliente, como nome, e-mail, documento e ações que fazem sentido naquele contexto.

Isso facilita a leitura e a manutenção, porque o código fica dividido em partes menores e com responsabilidades mais claras.

Exemplo prático

Imagine que um sistema precisa calcular um imposto específico.

Em vez de deixar essa regra espalhada em vários pontos do código, ela pode ser colocada em uma classe própria, com um nome que deixe claro qual imposto está sendo calculado.

Assim, quando for necessário alterar essa regra, fica mais fácil encontrar onde a lógica está e entender o impacto da mudança.

Reutilização de código

Um benefício importante da orientação a objetos é a possibilidade de reutilizar código de forma mais organizada.

A ideia não é copiar e colar trechos de código em vários lugares.

A ideia é criar estruturas reutilizáveis, com responsabilidades bem definidas, que possam ser usadas em diferentes partes do sistema quando fizer sentido.

Resumo

A Programação Orientada a Objetos é um paradigma que organiza o código em torno de entidades, objetos e relações.

Ela ajuda a criar sistemas mais fáceis de entender, manter e evoluir, principalmente quando o problema possui várias partes que interagem entre si.
