Java Fundamentos: linguagem Java

Visão geral da linguagem Java, sua relação com orientação a objetos, internet, bytecode e Máquina Virtual Java.

Java Fundamentos Parte 2 de 6

Java é uma linguagem muito associada à orientação a objetos, portabilidade e execução por meio da JVM.

Java e o paradigma orientado a objetos

Existem várias linguagens que permitem aplicar Programação Orientada a Objetos.

Uma das mais conhecidas é a linguagem Java.

Java ficou muito associada à POO porque sua forma de estruturar programas gira bastante em torno de classes, objetos, métodos, atributos e relações entre entidades.

Origem e contexto

Java foi apresentado publicamente em 1995 pela Sun Microsystems.

A ideia por trás da linguagem estava ligada à criação de software capaz de rodar em ambientes diferentes, incluindo dispositivos e computadores com características distintas.

Esse contexto ajuda a entender por que a portabilidade se tornou uma das marcas mais fortes do Java.

Java e a internet

Com o crescimento da internet, Java ganhou bastante atenção.

Durante um período, ele foi usado em recursos integrados a páginas web, em uma época em que a web ainda estava evoluindo rapidamente.

Hoje, muitos desses usos antigos não são mais comuns, mas Java continuou relevante em outras áreas, principalmente em sistemas corporativos, aplicações backend, APIs, sistemas bancários e aplicações de grande porte.

Como Java funciona de forma geral

O fluxo básico é este:

  1. O programador escreve código Java.
  2. Esse código é compilado.
  3. A compilação gera arquivos .class.
  4. Esses arquivos contêm bytecodes.
  5. A JVM executa esses bytecodes no ambiente onde ela está instalada.

Ou seja, o código Java não é executado diretamente pelo sistema operacional da mesma forma que um programa nativo comum.

Ele passa por uma camada intermediária: a JVM, sigla para Java Virtual Machine.

O papel da JVM

A JVM é responsável por executar o bytecode Java.

Em uma explicação inicial, podemos dizer que ela interpreta esse código intermediário.

De forma mais precisa, JVMs modernas também podem otimizar e compilar partes do programa em tempo de execução, dependendo da implementação e do comportamento da aplicação.

Para este primeiro contato com Java, o ponto principal é entender que a JVM cria uma camada entre o programa Java e o sistema operacional.

Por que isso foi importante

Essa estrutura ajudou Java a ser usado em diferentes ambientes.

Em vez de depender diretamente de um único sistema operacional ou de uma única arquitetura de hardware, o programa Java depende de uma JVM compatível instalada naquele ambiente.

Isso fortaleceu a ideia de escrever um programa e executá-lo em diferentes plataformas.

Resumo

Java é uma linguagem de programação fortemente ligada à orientação a objetos e à portabilidade.

Seu funcionamento passa pela compilação do código-fonte para bytecode e pela execução desse bytecode na JVM.

Essa combinação ajudou Java a se tornar uma linguagem muito usada em sistemas grandes, aplicações backend e ambientes corporativos.
